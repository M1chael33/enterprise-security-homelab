# Security & Lab Safety

This repository documents an isolated cybersecurity training environment.

- I performed all offensive testing only against systems I owned and intentionally configured for training.
- I did not use the lab against public systems, real users, or third parties.
- I intentionally omit real passwords and sensitive credentials from this repository.
- Any example IP addresses and data references are specific to the disposable training environment.
- I do not publish real secrets, tokens, API keys, or production credentials here.

I will continue keeping future offensive demonstrations restricted to authorized lab systems.
