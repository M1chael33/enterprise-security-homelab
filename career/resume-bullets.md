### Enterprise Security Homelab — Project Security Enterprise 101
**VirtualBox | Windows Server | Active Directory | Wazuh | Kali Linux | Ubuntu | Docker | Nmap | PowerShell**

- Built a six-VM enterprise cybersecurity homelab with Windows Server Active Directory, Windows/Linux endpoints, a corporate Ubuntu server, a Wazuh security server, and a Kali Linux attacker workstation.
- Configured AD DS, DNS, DHCP, domain authentication, Samba/Winbind, SSH, RDP, WinRM, Docker, MailHog, and isolated virtual networking.
- Deployed Wazuh agents and implemented File Integrity Monitoring for simulated sensitive enterprise data.
- Created and validated a custom Wazuh detection rule and alert monitor for protected-file activity.
- Simulated an authorized attack lifecycle covering reconnaissance, initial access, phishing, lateral movement, privilege escalation, data exfiltration, and persistence.
- Investigated generated attacker activity in Wazuh using endpoint telemetry, alert timelines, rule metadata, File Integrity Monitoring events, and timestamp correlation.
- Troubleshot Windows/Linux networking, DNS, SSH, Wazuh deployment, Apache/PHP, permissions, and remote-access configuration.
